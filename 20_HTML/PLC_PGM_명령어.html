MTR (Matrix Input)

MTR(s, n, d, n2);

입력 s로부터 8*n개의 스위치 상태를 읽어 d에 저장합니다.

피연산자(오퍼랜드) 사양
피연산자 설명
(s) 입력 선두 번호 (X0)
(n) 매트릭스 열 수 (8)
(d) 출력 선두 번호 (Y0)
(n2) 결과 저장 선두 (M0)
ST 프로그램 예제
// 8x8 키패드 읽기
// X0~X7 입력, Y0~Y7 출력
// M0~M63 에 결과 저장
MTR(X0, 8, Y0, M0);

"MTR은 스캔 방식이므로 속도가 중요할 경우 스캔 타임을 고려해야 합니다."

DSORTD (32-bit Sort)

DSORTD(EN, s1, n, s2, d1, d2);

(s1)부터 시작하는 BIN32(32비트) 데이터 (n)개를 오름차순/내림차순 정렬합니다.

피연산자 사양
피연산자 설명
(s1) 테이블 선두 디바이스 (D100)
(n) 정렬 데이터 수 (2~10)
(s2) 1회 비교 데이터 수
(d1) 정렬 완료 비트 (M0)
(d2) 시스템 전용 디바이스 (D2000)
ST 프로그램 예제
// D100부터 n개 데이터 정렬
// s2=2 (1스캔당 2개씩 비교)
DSORTD(SM400, D100, 6, 2, M0, D2000);

"32비트 데이터는 항상 2워드(D100+D101)를 한 쌍으로 처리합니다."

PWM (Pulse Modulation)

PWM(EN, s1, s2, d);

ON 시간(s1) 및 주기 시간(s2)을 가진 펄스를 대상 디바이스(d)로 출력합니다.

피연산자 사양
피연산자 설명
(s1) ON 시간 (1~65535 ms)
(s2) 주기 시간 (1~65535 ms)
(d) 펄스 출력 비트 (Y0)
ST 프로그램 예제
// 0.5초 ON, 1초 주기
// s1 < s2 조건을 만족해야 함
PWM(SM400, 500, 1000, Y0);

"PWM은 인버터 속도 제어나 히터 전력 제어에 주로 사용되는 핵심 명령어입니다."

🦾 시간 제어 핵심 정리

조드님, 이 명령어는 "시간"이 아니라 "스캔 횟수"로 동작해요!

1. 10ms 스캔 기준으로 계산하세요.
2. 1초를 원하면 n = 100
3. 3초를 원하면 n = 300
4. 10초를 원하면 n = 1000

이렇게 넣으면 기계가 부드럽게 가속합니다.
